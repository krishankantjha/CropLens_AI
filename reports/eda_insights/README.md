# EDA Insights Artifacts

This directory contains figures and tabular diagnostics generated by `research/notebooks/eda.ipynb`. Files use descriptive, stable names so that research-paper references and downstream reports remain understandable.

The notebook generates an `artifact_manifest.csv` after a successful run. It is the authoritative inventory of the current EDA exports. Regenerated artifacts should be reviewed visually and committed together with the notebook only when the underlying analysis intentionally changes.
